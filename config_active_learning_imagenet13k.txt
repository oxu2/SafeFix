# Active Learning Configuration for ImageNet 13K Dataset
# Dataset: 13,000 images total (1300 per class × 10 classes)
# This file contains optimized parameters for Active Learning on this scale

## Recommended Parameters for Different Scenarios

### Scenario 1: High Performance (sub_ratio=0.7, 9100 images)
# Best balance between performance and computational efficiency
--dataset imagenet
--model resnet
--use_active_learning True
--sub_ratio 0.7
--al_initial_labeled 450
--al_embedding_dim 256
--num_epochs 30
--batch_size 32
--lr 1e-3
--verbose True

### Scenario 2: Medium Performance (sub_ratio=0.5, 6500 images)  
# Good performance with moderate computational cost
--dataset imagenet

--al_embedding_dim 256
--num_epochs 25
--batch_size 32

--verbose True

## Parameter Explanations

# --use_active_learning True    : Enable Core-set based Active Learning (default: True)
# --sub_ratio 0.3-0.7          : Fraction of training data to select
#                                 0.3 = 3900 images, 0.5 = 6500 images, 0.7 = 9100 images
# --al_initial_labeled 300-450 : Initial labeled samples for Core-set algorithm
#                                 Should be 3-5% of total dataset (13000 * 0.03-0.05)
# --al_embedding_dim           : Embedding dimension for similarity calculation
#                                 ResNet: 256, CLIP: 512, ViT: 768

## Expected Performance Benefits

# Active Learning vs Random Selection (based on typical improvements):
# - sub_ratio=0.3: +3-5% accuracy improvement
# - sub_ratio=0.5: +2-4% accuracy improvement  
# - sub_ratio=0.7: +1-3% accuracy improvement

# The improvement is typically higher when using less data (lower sub_ratio)
# because Active Learning becomes more valuable when data is limited.
