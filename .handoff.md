- Rationale:
  - the training loop's post-train val/test evaluation and slice analysis only need model weights
  - they do not need optimizer or scheduler state
  - therefore the default `best.pth` / `last.pth` no longer need to store full training state

  - a temporary model-only checkpoint written from an existing Qwen3 pose checkpoint was `226.1 MB`
  - the existing full checkpoints are about `451 MB`
  - therefore the new default saves about `225 MB` per checkpoint
  - because `last.pth` is now off by default, the new default normally saves only one compact checkpoint (`best.pth`)
  - compared with the old default `best.pth + last.pth` full-checkpoint pair (about `902 MB` total), the new default usually saves about `676 MB` per run
- Resume semantics after this change:
  - `--resume <ckpt>` now expects a full training-state checkpoint and will error if optimizer state is missing
  - `--resume-model <ckpt>` is the intended path for the new default compact checkpoints such as `best.pth`
  - if strict continuation with optimizer / scheduler is needed later, save and use `last_resume.pth`
