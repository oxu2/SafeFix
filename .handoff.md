## 2026-04-09 Codex / OpenAI Account Switch Note

If you log out of OpenAI account 1 in VS Code Codex and then log in with account 2, do not assume the new account will seamlessly inherit the full chat context from account 1.

What persists:
- The local workspace state persists.
- Repository files, uncommitted edits, generated artifacts, and `git diff` remain in the same filesystem workspace.
- Local Codex state appears to keep session records separately from auth, so local resume may still be possible on the same machine.

What does not reliably persist across accounts:
- OpenAI-side chat history, memory, account-scoped workspace metadata, and other account-bound conversation context should be treated as separate between account 1 and account 2.
- The implicit context inside the current conversation should not be relied on after switching accounts.

Safe handoff rule:
- Write the current status, changed files, decisions, and next steps into `.handoff.md` before switching accounts.
- After switching accounts, continue from the codebase state plus this handoff file, not from the assumption that the prior chat thread is still fully available.
